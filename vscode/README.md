# LangGraph Studio (Unofficial)

A community-built Studio for your local LangGraph Agent Server, right inside VS Code:
graph view, thread log, interrupts, assistants and memory. Everything runs against the
server you point it at; no cloud account is involved.

Command: `LangGraph Studio (Unofficial): Open`. Settings: `langgraphStudio.target`, `langgraphStudio.customHeaders`.
